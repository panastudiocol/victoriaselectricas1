# Victorias Eléctricas · Carruajes Clásicos

Sitio web de Victorias Eléctricas.

- `index.html` — página principal (computador y tablet). En celular muestra la versión app.
- `app.html` — versión app para celular (se carga sola dentro de `index.html`).
- `support.js` — motor de la página.
- `assets/` — imágenes, videos, logos, favicon y traducciones (`i18n.json`).

## Publicar en GitHub Pages
1. Sube todo el contenido de esta carpeta a la raíz del repositorio.
2. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)`.
3. Espera uno o dos minutos y abre la dirección que te muestra GitHub.
